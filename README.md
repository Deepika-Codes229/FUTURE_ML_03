# 🚀 AI Resume Screening System

## 📌 Overview

This project is an AI-powered Resume Screening System built using Machine Learning and NLP (Natural Language Processing).

The system automatically analyzes resumes, extracts skills, compares resumes with job descriptions, and ranks candidates based on matching scores.

---

## ✨ Features

✅ Resume Text Cleaning & Preprocessing  
✅ Skill Extraction using NLP  
✅ TF-IDF Vectorization  
✅ Cosine Similarity Matching  
✅ Candidate Ranking System  
✅ Missing Skill Analysis  
✅ Interactive Streamlit Web Application  
✅ Candidate Ranking Graphs & Visualization

## 🧠 Machine Learning Concepts Used

### 🔤 TF-IDF Vectorization

TF-IDF converts resume and job description text into numerical vectors for analysis.

### 🔍 Cosine Similarity

Cosine Similarity measures how closely a resume matches the given job description.
