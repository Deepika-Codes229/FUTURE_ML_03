# AI Resume Screening System

## Overview

This project is an AI-powered Resume Screening System built using Machine Learning and NLP.

The system screens resumes automatically based on job descriptions and ranks candidates according to their skills and relevance.

---

## Features

- Resume Screening
- Skill Extraction
- Candidate Ranking
- Missing Skill Analysis
- TF-IDF Vectorization
- Cosine Similarity Matching
- Streamlit Web Application

---

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- NLP
- TF-IDF
- Cosine Similarity
- Matplotlib

---

## Machine Learning Concepts

### TF-IDF Vectorization

TF-IDF converts resume text into numerical vectors.

### Cosine Similarity

Cosine similarity measures similarity between resumes and job descriptions.

---

## Project Workflow

1. Resume text cleaning
2. Skill extraction
3. Job description processing
4. TF-IDF vectorization
5. Similarity calculation
6. Candidate ranking
7. Missing skill detection

---

## How to Run

Install libraries:

```bash
pip install streamlit pandas matplotlib scikit-learn
```

Run project:

```bash
streamlit run app.py
```
